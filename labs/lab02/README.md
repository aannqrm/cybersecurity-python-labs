# Лабораторна робота №2. Об'єктно-орієнтоване програмування та аналіз даних безпеки

## Опис проекту
У цій лабораторній роботі реалізовано:
1. **Завдання 1 (`task1.py`)**: ООП-модель керування обліковими записами користувачів, сесіями, аутентифікацією та журналюванням подій безпеки.
2. **Завдання 2 (`task2.py`)**: Утиліта для аналізу термінів дії SSL/TLS сертифікатів та перевірки стійкості алгоритмів підпису (Варіант 10).

## Інструкція з запуску

### Завдання 1 (Демонстрація ООП):
```bash
python -m labs.lab02.task1
python -m labs.lab02.task2
